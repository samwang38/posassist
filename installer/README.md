# PosAssist — POS 輔助面板

> **1.4.0 的變動**：
> - **圖形化設定**：安裝完會直接問要不要設定預約系統帳密，不必再手改文字檔。
>   設定視窗有「測試連線」，當場就知道帳密對不對。之後在面板的預約區按「設定」也能開。
> - **自動更新**：開啟 EPB 時會檢查有沒有新版並自動更新到最新。
>   更新只發生在 EPB 啟動之前，**絕不會在結帳中途換程式**；
>   檢查限時 5 秒、下載限時 20 秒，沒網路就直接用現有版本開，不會拖到開店。
>   下載後比對 sha256，不符就丟掉不換；上一版永遠留在 `posassist.jar.prev`。
>   不想自動更新：設定視窗取消勾選，或在 `config/posassist.properties` 設 `autoUpdate=false`。
> - **更新不會動到你的設定**：帳密、結帳代碼、面板模式都原封不動。

> **1.3.0 的變動**：側欄上下兩半改成**各佔一半、分界固定**——結帳代碼九宮格的位置
> 不會再因為會員有幾筆預約而上下跳，店員按代碼可以靠肌肉記憶。
> 會員資訊超過一半時上半可捲動，不會擠壓下半。
> 側欄分頁「會員」改名為**「輔助工具」**（它現在同時包含會員查詢與結帳代碼）。

> **1.2.0 的變動**：側欄下半部加了**自訂結帳代碼**九宮格。
> 分類頁籤 + 3 欄按鈕，每顆顯示名稱與代碼，**點一下直接帶入 POS**
> （等同自己打代碼按 Enter，POS 照常驗證與計價）。
> 清單放在 `config/codes.txt`，可以直接改檔，也可以用面板右上角的「編輯」增刪與調順序；
> 每次存檔會把前一版留成 `codes.txt.bak`。
> 順帶修掉會員欄位浮在側欄中間、上方留一大塊空白的問題。

> **1.1.0 的變動**：結帳時面板改為**嵌進 EPB 左側欄**，不再是浮動視窗。
> 側欄變成「會員／應用程式」兩個分頁，POSN 開啟時預設顯示會員，關掉 POSN 自動還原。
> 想收合側欄請用 EPB 自己的 **Toggle Full Screen** 按鈕（應用程式標題列左邊那個小圖示），
> 收起時面板會一起收起。
>
> 要回到舊的浮動視窗行為：在 `config/posassist.properties` 設 `panelMode=floating`，重開 EPB。

結帳時在 POSN 畫面旁邊顯示一個置頂小面板，目前的功能是**會員查詢**：

- 面板上有一個常駐輸入框，打電話或會員代碼，**按 Enter 送出查詢**。
- 顯示會員代碼、姓名、電話、Email、等級。
- POS 上一選到會員，面板自動跟著顯示那位會員。
- **點一下會員代碼**就把它帶進 POS 的會員欄位，等同你自己打進去再按 Enter。

## 這個外掛不會做的事

- **不修改 EPB 任何原廠檔案。** 只新增 `<EPB_ROOT>/EPB/PosAssist/` 一個目錄。
- **不寫入任何資料庫。** 全程只跑 `SELECT`，不碰 POSMAS、POSLINE、發票、日結。
  「帶入 POS」只是把代碼填進 POS 畫面上的欄位並送出，後續驗證與載入完全由 POS 自己處理，
  跟你手動打進去一模一樣；POS 若把會員欄位鎖住，面板就不會硬塞。
- **不主動搶鍵盤焦點。** 面板視窗設 `setAutoRequestFocus(false)`，出現或移動時都不會自己拿焦點；
  只有你主動點輸入框才會。帶入 POS 之後、按 Enter 或 Esc 之後，焦點都會主動還給 POS。
  （提醒：游標停在面板輸入框時掃條碼，條碼會進面板而不是 POS —— 按 Esc 就把焦點還回去。）
- **不動原本的 EPB 捷徑。** 這是「第二個捷徑」，外掛有任何問題，改用原本的捷徑開就完全正常。

## 安裝

雙擊 `安裝_PosAssist.command`。

安裝器會自己找到 EPB 安裝目錄與 Java、複製檔案、產生啟動器、放桌面捷徑，
最後跑一次自我檢查。

安裝完成後，桌面會多一個 **EPB（含輔助面板）**。用它開 EPB，
登入方式跟平常完全一樣。

### 安裝到非標準路徑

```bash
POSASSIST_EPB_ROOT=/path/to/EPBrowser ./安裝_PosAssist.command
```

### 焦點要回到別的欄位

預設帶入會員後焦點會回到 POS 的品項輸入欄 `pluIdTextField`。若你的 POS 版面不同，
在啟動器的 java 參數加上：

```text
-Dposassist.posInputField=欄位名稱
```

## 使用

1. 用新的桌面捷徑開 EPB，正常登入。
2. 開 POS（POSN）。面板會自動出現在 POS 畫面右側，放不下時自動改靠左。
3. 要查會員，在面板的輸入框打電話或會員代碼，按 Enter 送出（至少 3 碼）。
4. 查到之後，**點一下藍色的會員代碼**就帶進 POS，焦點會自動回到 POS 的品項輸入欄，
   可以直接接著掃條碼，不用再用滑鼠點回去。
5. 按 Esc 清空輸入框並把焦點還給 POS。
6. POS 自己選到會員時，面板會自動顯示那位會員（前提是你沒有正在輸入框裡查東西）。
7. 面板可以拖到喜歡的位置；拖過之後就不再自動貼齊。

## 預約整合（選用）

查到會員時，一併列出他近 30 日的預約：預約單號、產品名稱、預約狀態、登記日期。

**預設不啟用。** 要開啟，在安裝目錄 `<EPB_ROOT>/EPB/PosAssist/config/` 底下：

```bash
cp reservation.properties.example reservation.properties
chmod 600 reservation.properties
```

填入**這家門市自己的**預約系統帳號密碼（每家店不同），重開 EPB 即生效。

運作方式：背景每小時抓一次近 30 日資料建索引，**結帳時只查記憶體、不連網**，
所以不會拖慢結帳。抓取失敗會沿用上一份資料，並在 log 留一筆。

面板上會標示資料時間（例「近期預約 · 15:40 更新」），店員知道資料多新。

排序不是單純照日期，而是**照店員需要處理的急迫性**：

1. 已到貨、保留 —— 東西在店裡等客人拿，最該當場提醒
2. 已預約 —— 還沒到貨
3. 已取貨 —— 已完成
4. 其他（已取消、放棄、已送達等）

同一組之內再依登記日期新到舊。所以三個月前的一筆「保留」會排在昨天的「已取貨」前面。

點一下藍色的**預約單號**，會記住它並複製到剪貼簿；接著按 F10 開序號視窗時，
會自動填進「預約單號」欄。（F10 視窗是 modal，它開著時面板點不動，所以是先點後填。
自動填沒生效時，單號已在剪貼簿，直接貼上即可。）

⚠️ 密碼是**明文**存在這台電腦上。請確認這台機器只有店內人員使用，並保持 600 權限。
移除外掛時這個檔案會保留，重裝不必重填。

沒有這個設定檔時，面板行為與未加這個功能時完全相同。

## 移除

雙擊 `移除_PosAssist.command`。

移除器只會刪自己安裝的東西。如果那個資料夾裡有它不認得的檔案，會直接停手不刪，
避免誤刪別人放的資料。

移除後 EPB 完全回到原狀。

## 出問題時

**第一步永遠是：改用原本的 EPB 捷徑。** 那條路徑沒有外掛，一定正常。

接著把這兩個東西給開發者：

1. 自我檢查的輸出：安裝目錄 `<EPB_ROOT>/EPB/PosAssist/` 底下雙擊
   `驗證_PosAssist.command`。（安裝時也會自動跑一次）
2. `<EPB_ROOT>/EPB/PosAssist/logs/posassist.log`

log 只記錄外掛自己的事件與例外，**不記錄會員電話、會員代碼或查詢內容**。

## EPB 改版之後

EPB patch 可能改動 POSN 的內部欄位名稱。真的發生時，外掛的行為是
**該項資訊不顯示，並在 log 留一筆警告** —— 不會影響結帳，也不會讓 EPB 出錯。

重跑一次自我檢查就知道是哪一項失效了。

## 需要的權限

外掛沿用你登入 EPB 的身分查資料，**不需要額外權限、不需要資料庫帳密、
不需要設定任何連線資訊**。能開 POS 的機器就能用。
